## Команды бота

Перед работой с календарем нужно войти или зарегистрироваться:

| Команда | Описание |
| --- | --- |
| `/start` | Приветствие и краткая подсказка по началу работы. |
| `/register` | Зарегистрировать текущего Telegram-пользователя в боте. |
| `/login <telegram_id>` | Подключить свой Telegram ID к учетной записи. Можно вызвать `/login` без аргумента, тогда используется ID текущего пользователя. |

Команды для событий:

| Команда | Описание |
| --- | --- |
| `/calendar [telegram_id]` | Показать свой календарь. Если указан `telegram_id`, дополнительно покажет публичные события этого пользователя. |
| `/create_event <name> <date> <time> [details]` | Создать событие. Пример: `/create_event Встреча 2026-08-01 14:30 Обсудить проект`. |
| `/get_event <event_id>` | Показать событие по ID. |
| `/update_event <event_id> [name] [date] [time] [details]` | Обновить событие. Можно менять только название или передать дату, время и детали. |
| `/delete_event <event_id>` | Удалить событие по ID. |
| `/list_events` | Показать список своих событий. |
| `/export_events` | Получить кнопки для выгрузки своих событий в JSON или CSV. |
| `/share_event <event_id>` | Сделать событие публичным для других пользователей. |
| `/unshare_event <event_id>` | Скрыть событие из публичного списка. |
| `/shared_events <telegram_id>` | Показать публичные события выбранного пользователя. |

Команды для встреч и приглашений:

| Команда | Описание |
| --- | --- |
| `/invite_user <event_id> <user_id> [duration_minutes]` | Пригласить пользователя на событие. По умолчанию длительность встречи — 60 минут. |
| `/appointments [id\|pending\|confirmed\|cancelled]` | Показать свои встречи, детали встречи по ID или отфильтровать встречи по статусу. Также поддерживаются статусы `ожидание`, `подтверждено`, `отменено`. |
| `/list_appointments [id\|pending\|confirmed\|cancelled]` | Алиас команды `/appointments`. |

Дата в командах принимает форматы вроде `01.08.2026`, `2026-08-01`,
`1 августа 2026`, `сегодня`, `завтра`, `послезавтра` или `через 3 дня`.
Время указывается в формате `ЧЧ:ММ`, например `09:30`.

## Запуск через Docker Compose

1. Создайте `.env` на основе `.env.example` и укажите `TELEGRAM_TOKEN`.
2. Запустите все сервисы:

```bash
docker compose up --build
```

Админка Django будет доступна на `http://localhost:8000/admin/`.

Для кнопок выгрузки событий в Telegram укажите в `CALENDAR_EXPORT_BASE_URL`
публичный HTTP(S)-адрес Django-приложения. `localhost`, `127.0.0.1` и адреса
из Docker-сети Telegram отклоняет в inline-кнопках.

## Автоматические тесты

Критические узлы покрыты тестами Django `unittest`: логика календаря, встречи,
публичные события, экспорт, REST API и парсинг команд Telegram-бота.

```bash
.venv/bin/python tg_bot_calendar/manage.py test calendar_bot --settings=tg_bot_calendar.test_settings
```

Тесты используют отдельные SQLite-настройки и не требуют запущенного PostgreSQL
или Docker Compose.
